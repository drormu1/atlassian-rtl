# Atlassian RTL Support & Fixes

Enhance your Atlassian Jira and Confluence user experience with seamless Right-to-Left (RTL) language support.

## Overview
This script resolves common UI, layout, and text alignment bugs that occur when working with mixed RTL (Hebrew, Arabic, Persian, Urdu) and LTR (English, code snippets) content within Jira Enterprise and Confluence spaces.

## Key Features
- **Automatic Direction Detection:** Smoothly renders bidirectional text without breaking layout or alignment.
- **RTL UI Polishing:** Fixes broken margins, flipped icons, and misaligned form elements.
- **Code & Markdown Preservation:** Keeps code blocks, URLs, and technical snippets correctly formatted LTR.
- **Cross-Product Compatibility:** Designed for Jira Software, Jira Service Management, and Confluence.
