# תמיכה ותיקוני RTL עבור מוצרי Atlassian

שיפור חווית המשתמש והתצוגה בשפות הנכתבות מימין לשמאל (Hebrew / Arabic) במערכות Jira ו-Confluence.

## סקירה כללית
הסקריפט פותר בעיות כיווניות (RTL), יישור טקסט ושיבושי UI הנפוצים בעבודה עם תכנים מעורבים (עברית/ערבית לצד אנגלית וקוד) ב-Jira Enterprise ו-Confluence.

## תכונות עיקריות
- **זיהוי כיווניות אוטומטי:** תצוגה קבילה של טקסט דו-כיווני (BiDi) ללא שבירת תוכן.
- **תיקוני ממשק (UI):** יישור שדות, מרחקים (Margins) ואייקונים המשתבשים בתצוגת RTL.
- **שמירה על קוד ואנגלית:** קטעי קוד, נתיבי מערכת ו-URLs נשארים מיושרים לשמאל (LTR) כנדרש.
- **תמיכה במוצרים:** מותאם ל-Jira Software, Jira Service Management ו-Confluence.
